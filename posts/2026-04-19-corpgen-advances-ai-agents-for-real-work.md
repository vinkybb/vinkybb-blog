# CORPGEN：推动 AI Agent 投入真实职场工作

## 背景：基准测试与现实工作的鸿沟

到上午十点，一名典型的知识工作者可能已经同时在处理客户报告、预算表格、演示文稿和邮件积压——这些任务相互依赖，同时都需要关注。如果 AI agent 要在这样的环境中真正发挥作用，它们也需要以同样的方式运作。然而，当前最先进的 AI 模型都是被逐个任务评估的，而非同时处理数十个任务。

微软研究院的研究团队发现，现有 AI agent 基准测试存在根本性局限：只测试单个任务的执行能力，而真实工作场景要求同时管理多个相互依赖的任务。这种测试方法与实际生产力需求之间存在显著差距。研究显示，当并发任务从12个增加到46个时，主流计算机使用代理的完成率从16.7%跌落至8.7%。这一现象揭示了当前 AI agent 在面对真实职场压力时的脆弱性。

## 核心创新：多视野任务环境（MHTEs）

为解决这一评估缺陷，研究团队开发了多视野任务环境，这是一种让 agent 必须同时管理多个复杂任务的新型评估环境。每个任务需要在5小时的单一会话中完成10到30个相互依赖的步骤。通过大规模运行 MHTEs，团队识别出当前 agent 在并发任务执行中的四个关键弱点。

首先是内存溢出问题：agent 无法同时保持多个活跃任务的细节信息。其次是跨任务信息干扰：来自一个任务的信息会干扰对另一个任务的推理。第三是任务依赖复杂性：任务并非简单序列依赖，而是形成复杂的网络结构，agent 必须不断检查上游工作是否完成才能推进下游工作。第四是重新优先级排序需求：每个行动周期都需要对所有活跃任务重新优先级排序，而不仅仅是恢复之前的执行点。

## 技术架构：CORPGEN 的四大机制

CORPGEN 引入了"数字员工"概念：具有持久身份、角色特定专业知识、真实工作日程的 LLM 驱动的 AI agent。它们通过 GUI 自动化操作 Microsoft Office 应用程序，能够在 MHTEs 中持续数小时稳定执行任务。

针对并发任务执行的四个弱点，CORPGEN 通过定向设计的四大机制逐一解决。分层规划机制将目标分解为每日目标和即时决策，使 agent 能够基于结构化计划行动，而非在每个步骤前审查所有可用任务。隔离子代理机制在隔离上下文中执行复杂操作（如网络研究），防止跨任务污染。分层记忆系统支持选择性召回任务相关信息，而非在活跃上下文中保留所有信息。自适应摘要机制压缩常规观察同时保留关键信息，控制记忆增长。

这四大机制不依赖于特定基础模型。研究团队在三种不同 agent 上测试 CORPGEN，均观察到一致增益。改进来自架构设计，而非特定模型的能力强度。

## 协作模式：自组织的虚拟组织

当多个数字员工在同一环境中运作时，协作通过标准通信渠道自然形成，无需预设协调规则。一名员工发送邮件请求数据；另一名在下一周期接收，利用其记忆处理并回复。这种交换模拟真实职场沟通。代理之间无共享内部状态，协调完全通过 email 和 Microsoft Teams 进行——这正是许多工作者使用的相同渠道。

随时间推移，这些独立交换形成可识别的组织模式。某些代理承担领导角色，其他提供支持，共享文档成为连接纽带。当通信路径中断（如邮件投递错误），代理会通过替代渠道重新路由消息保持工作推进。结果是虚拟组织行为如同真实组织，而无需显式编程。

## 评估结果：架构设计的力量

研究团队在组合多达46个任务的六小时单会话基准上评估 CORPGEN。三大发现尤为突出：基线系统随负载增加性能下降，而 CORPGEN 维持甚至提升完成率。在46个任务时，CORPGEN 完成15.2%任务，基线仅4.3%，约为3.5倍增益。经验学习驱动最大增益。当依次引入组件：编排层、认知工具、经验学习，前两者产生适度改进。经验学习——agent 存储已完成任务记录并在遇到结构相似工作时复用——带来最大增幅，将完成率从8.7%提升至15.2%。评估方法论改变结果认知。检查 agent 实际输出文件时，结果与人类判断约90%一致；基于截图和行动日志的评估仅约40%一致。这一差距表明，常见评估方法可能低估 agent 实际完成的工作。

## 意义与展望

研究表明，记忆和检索——而非仅仅是原始模型能力——可能是让 agent 在现实世界工作的关键瓶颈。最大增益来自经验学习。从先前成功学习并将这些模式应用于结构相似任务的 agent，构建了对孤立响应每个任务的系统的优势。

CORPGEN 还开启了 AI agent 协作的新视角。下一步包括测试 agent 能否跨多个工作日维持记忆、团队协作时的协调方式，以及探索通过结合不同软件交互方法使 agent 更快更可靠。这一架构无关且模块化的设计意味着，随着底层模型改进，CORPGEN 将直接获益——改进来自系统设计，而非任何单一基础模型。
