# Agents SDK 的下一个演进阶段

## 背景介绍

在人工智能应用开发领域，构建可靠、安全的 Agent 系统一直是个挑战。开发者需要的不仅是强大的模型，更需要一套能支持 Agent 跨文件操作、命令执行、代码编写，并在多步骤任务中持续工作的系统架构。现有的解决方案各有短板：模型无关框架虽然灵活但无法充分发挥前沿模型能力；模型提供商 SDK 虽然贴近模型但缺乏足够的 Harness 可见性；托管 Agent API 虽然简化部署但限制了运行环境和敏感数据访问。

OpenAI 最新发布的 Agents SDK 正式引入了两项关键技术特性——模型原生 Harness 和原生沙箱执行，为开发者提供了标准化的基础设施，既易于上手，又针对 OpenAI 模型进行了深度优化。这次更新填补了从原型到生产之间的基础设施空白，让 Agent 开发真正走向工程化。

## 核心内容

### 模型原生 Harness

Harness 是 Agent 与计算机系统交互的核心桥梁。更新后的 Agents SDK Harness 提供了多项关键能力：可配置内存让 Agent 能够保持上下文连贯性；沙箱感知编排让执行流程与隔离环境协同；Codex 级别的文件系统工具让 Agent 可以安全地读写文件；标准化集成则引入了前沿 Agent 系统中常见的基础组件。

这些基础组件包括：通过 MCP（Model Context Protocol）实现的工具调用、通过 Skills 实现的渐进式能力披露、通过 AGENTS.md 定义的自定义指令、通过 Shell 工具实现的代码执行、通过 Apply Patch 工具实现的文件编辑等。Harness 会持续集成新的 Agent 模式和基础组件，开发者可以专注于领域特定逻辑，而不是核心基础设施更新。

更重要的是，Harness 的设计与前沿模型的自然运行模式深度对齐。这种对齐让 Agent 在复杂任务中——尤其是长期运行或跨多种工具系统协调的任务——表现更稳定、性能更出色。

### 原生沙箱执行

许多有用的 Agent 需要一个工作空间来读写文件、安装依赖、运行代码、安全使用工具。Agents SDK 现在原生支持沙箱执行，开发者无需自行拼凑执行层。

SDK 支持多种沙箱提供商：Blaxel、Cloudflare、Daytona、E2B、Modal、Runloop 和 Vercel。开发者可以使用内置支持，也可以自带沙箱环境。为了使环境在不同提供商间可移植，SDK 还引入了 Manifest 抽象来描述 Agent 工作空间——开发者可以挂载本地文件、定义输出目录、从 AWS S3、Google Cloud Storage、Azure Blob Storage 和 Cloudflare R2 等存储提供商引入数据。

这为开发者提供了一致的方式来塑造 Agent 环境，从本地原型到生产部署。同时，模型也获得了可预测的工作空间：在哪里找到输入、在哪里写入输出、如何在长期任务中保持工作有序。

## 技术分析

### 安全架构设计

Agent 系统应该默认防御提示注入和数据渗出攻击。Agents SDK 采用 Harness 与计算分离的架构，确保凭证不会进入模型生成代码执行的 环境。这种设计理念体现了安全优先的原则，为生产环境中的 Agent 运行提供了必要保障。

### 持久执行能力

当 Agent 状态被外部化后，丢失沙箱容器并不意味着丢失运行。Agents SDK 内置快照和恢复机制，可以在原始环境失败或过期时，将 Agent 状态恢复到新容器并从最后一个检查点继续执行。这对于需要长期运行的复杂任务至关重要，大幅提升了系统的可靠性。

### 可扩展性优势

沙箱架构还带来了可扩展性提升。Agent 运行可以使用单个或多个沙箱、仅在需要时调用沙箱、将子 Agent 路由到隔离环境、跨容器并行执行以加快速度。这种灵活性让 Agent 系统可以根据任务特性动态调整资源使用，既节省成本又提升效率。

## 总结

Agents SDK 的这次更新标志着 Agent 开发进入新阶段。模型原生 Harness 与原生沙箱执行的结合，为开发者提供了从原型到生产的完整基础设施，既保持了灵活性又确保了安全性和可靠性。

新能力现已通过 API 对所有客户开放，使用标准 API 定价（基于 tokens 和工具使用）。Python 版本率先发布，TypeScript 支持计划未来推出。OpenAI 正在将更多 Agent 能力——包括代码模式和子 Agent——带到 Python 和 TypeScript。

对于需要构建自动化代码助手、文件处理 Agent、多工具协同智能体或长任务执行系统的开发者而言，这次更新提供了真正工程化的基础设施，让 Agent 从实验走向生产成为现实。随着更多沙箱提供商、集成方式和生态工具的支持，Agents SDK 正成为 Agent 开发领域的标准化选择。
